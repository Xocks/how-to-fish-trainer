## 可直接复制的视频简介

这是我基于开源项目 `fredwangwang/how-to-fish-trainer` 制作的 **Xocks 社区改版**，不是原作者发布的官方更新。原版已有生命、饱食度、空中跳、无限弹药、伤害倍率和增加金币等功能；我的改版先加入 F7/F8 物品生成器，0.3 版本继续加入锁头、物品/生物标签、鼠标面板和新版安全门禁。

本次新增内容：

- F7 自动读取游戏运行时物品目录，显示物品 ID 和名称；
- F8 在人物相机前方约 2 米生成当前物品，可用于鱼、枪械和普通物品；
- ID 53“角色”以及 `deadplayer` 网络角色显示红色 `×` 并永久阻止，防止缺少玩家初始化状态时闪退；
- F9 持枪 ADS 并按住右键时锁定生物头部；私有测试确认后可测试玩家目标；
- F11 显示物品和生物名称、距离、分类颜色，遮挡目标会变暗；
- Insert 打开鼠标控制面板，可调整锁头和标签参数；
- 单人/房主使用原生生成；普通客户端仅在私有测试确认后请求安全物品，并在不同步时自动关闭；
- 任务和未知物品带红色 `!`，生成前需要二次确认；
- 500ms 防连点，避免短时间创建大量网络对象；
- 生成调用转到 Unity 主线程，并加入补丁恢复握手和 Mono 字符串生命周期修复；
- 物品列表会根据终端大小自动调整栏数和每页容量，缩放窗口不再残留旧画面；
- 新增脱敏诊断包和单次生成探针，方便定位闪退与兼容问题。

当前代码版本是 `0.3.0rc1`。程序会先校验当前 `Assembly-CSharp.dll` 的哈希和 Mono 契约，未知版本不会安装补丁。建议使用临时存档，并优先在单人游戏或自己作为房主时测试。该工具由外部控制器在运行时连接 Mono，不会替换游戏安装文件，也不会向游戏目录安装 Mod。

## 60–90 秒口播稿

大家好，这是我在开源 How to Fish Trainer 基础上制作的 Xocks 改版。先说明一下，生命锁定、无限跳跃、无限弹药、伤害倍率和增加金币等功能来自原版；物品生成器、角色防闪退、枪械锁头、物品和生物标签以及鼠标面板是 Xocks 改版增加的部分。

按 F7 会从游戏运行时自动读取可生成物品，不是手工写死一个简单列表。现在目录会跟随窗口大小重新排版，大窗口一行显示四组 ID 和物品，窄窗口会自动减少栏数。输入 ID 确认后，按 F8 就会通过游戏自己的生成命令，在相机前方生成一个物品。

为了减少误操作，任务和未知物品会显示红色感叹号并要求再次确认；会导致闪退的“角色”对象直接显示叉号并禁止选择。F9 是枪械锁头，F11 是物品和生物标签，Insert 可以打开鼠标面板。普通客户端实验不会伪装成房主，只在好友私有测试房中请求安全物品。

之前测试中遇到过物品出现后游戏闪退的问题，所以改版又加入了 Unity 主线程调度、补丁恢复握手和字符串生命周期修复。当前仍然是 RC 测试版，建议大家使用临时存档。源码、原项目链接和使用说明都放在视频简介里。

## 建议演示顺序

1. 开场先展示改版仓库、上游仓库和版本号，明确改版关系。
2. 启动游戏进入临时单人存档，再启动外置修改器并展示成功连接。
3. 按 F7 展示运行时目录，演示“角色”红色 `×` 无法选择，再拖动窗口展示响应式排版。
4. 输入一条鱼的 ID，按 F8 生成并展示拾取、背包和丢弃。
5. 输入一把枪的 ID，生成后展示拾取和射击。
6. 展示带红色 `!` 的特殊物品二次确认，但不要在正式存档生成。
7. 持枪 ADS，按 F9 后按住右键演示生物锁头、遮挡释放和换枪释放。
8. 按 F11 展示物品/生物名称、距离和遮挡变暗，再按 Insert 演示鼠标设置。
9. 如果有双客户端私有房，再展示客户端“部分保护”和一次安全物品请求；必须同时录下房主视角，不能只看客户端 HUD。
10. 最后按 F10 安全退出，并展示源码、下载位置和 MIT 许可说明。

## 发布时建议保留的提示

- 工具仅用于学习、研究和个人游戏体验，请遵守游戏规则及相关平台条款。
- 不要在陌生人的联机房间中影响他人体验。
- RC 版本并不代表所有物品和所有游戏更新都经过验证。
- 未签名的 PyInstaller 程序可能显示“未知发布者”；应提供发布包 SHA-256，不要引导观众关闭安全软件。
