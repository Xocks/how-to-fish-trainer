## 可直接复制的视频简介

这是我基于开源项目 `fredwangwang/how-to-fish-trainer` 制作的 **Xocks 社区改版 v0.3.0**，不是原作者发布的官方更新。它和常见 Mod 最大的不同是：程序独立运行，不向游戏目录安装 DLL、不替换游戏文件；连接 Unity Mono 后在运行时读取真实物品目录并执行功能，退出时恢复补丁。

原版已有生命、饱食度、空中跳、无限弹药、伤害倍率和增加金币等功能；Xocks 改版增加了运行时物品生成器、角色防闪退、360°目标锁定、物品/生物 ESP、鼠标控制面板、第三人称原生本体动作链、静默自瞄实验和脱敏诊断包。

本次新增内容：

- F7 自动读取游戏运行时物品目录，显示物品 ID 和名称；
- F8 在人物相机前方约 2 米生成当前物品，可用于鱼、枪械和普通物品；
- ID 53“角色”以及 `deadplayer` 网络角色显示红色 `×` 并永久阻止，防止缺少玩家初始化状态时闪退；
- F9 持枪 ADS 并按住右键时，360°锁定世界距离最近的已启用目标；默认鱼和鸟，可选其他生物，玩家默认关闭并要求好友/私房确认；
- F11 最高 60 FPS 更新物品和生物名称、距离与分类颜色，字体大小可调；
- Home 开关可调距离、高度和左右肩位的第三人称相机，并从当前角色的网格、材质与骨骼建立不含脚本和网络组件的本机显示镜像；
- End 开关静默自瞄实验：镜头不跟随，开火瞬间修正保留原散布，实体弹丸模式只转向本地玩家弹丸并在遮挡后停止；
- 好友/私房实验页提供互斥的“低头朝后”和“高速身体转圈”，只使用游戏原有姿态发送频率并立即恢复本机视角；远端命中箱效果不作承诺；
- Insert 打开不会带动游戏视角的鼠标面板，并新增分层物品生成器；
- 单人/房主使用原生生成；普通客户端仅在私有测试确认后请求安全物品，并在不同步时自动关闭；
- 任务和未知物品带红色 `!`，生成前需要二次确认；
- F8 松开按键时只触发一次，并增加 400ms 请求去重，避免按住按键重复创建对象；
- 引擎资源分为可见模型预览和仅诊断资源；模型预览只复制 Mesh/Sprite，不执行原 Prefab 脚本，也不能拾取或同步；
- 生成调用转到 Unity 主线程，并加入补丁恢复握手和 Mono 字符串生命周期修复；
- 物品列表会根据终端大小自动调整栏数和每页容量，缩放窗口不再残留旧画面；
- 新增脱敏诊断包和单次生成探针，方便定位闪退与兼容问题。

当前发布版本是 `v0.3.0`。程序会先校验当前 `Assembly-CSharp.dll` 的哈希和 Mono 契约，未知版本不会安装补丁。第三人称本体不使用手写假动作，而是复用游戏现有的 PlayerLegs、PlayerHands、PlayerBody 与 IK 数据链；诊断会记录原生动作阶段和恢复状态。静默弹道、玩家目标、网络姿态和普通客户端能力属于好友/私房实验功能，服务器认可及远端命中箱必须以双客户端实测为准。

## 60–90 秒口播稿

大家好，这是我在开源 How to Fish Trainer 基础上制作的 Xocks 改版。它不是往游戏目录里塞 DLL 的 Mod，而是一个可以独立运行、退出后恢复补丁的外置程序。先说明一下，生命锁定、无限跳跃、无限弹药、伤害倍率和增加金币等功能来自原版；运行时物品生成器、角色防闪退、枪械锁头、物品和生物标签、第三人称以及鼠标面板是 Xocks 改版增加的部分。

按 F7 会从游戏运行时自动读取可生成物品，不是手工写死一个简单列表。现在目录会跟随窗口大小重新排版，大窗口一行显示四组 ID 和物品，窄窗口会自动减少栏数。输入 ID 确认后，按 F8 就会通过游戏自己的生成命令，在相机前方生成一个物品。

为了减少误操作，只有真实任务物品和爆炸物要求再次确认；普通鱼不再误报危险。会导致闪退的“角色”和网络管理对象直接禁止选择。F9 是 360°最近鱼锁定，F11 是最高 60 FPS 的物品和生物标签，Insert 面板新增鼠标生成器且不会带动游戏视角。紫色引擎对象只在本机生成，不会同步给其他玩家。

之前测试中遇到过物品出现后游戏闪退和第三人称 T Pose、人物上漂的问题，所以改版加入了 Unity 主线程调度、补丁恢复握手、字符串生命周期修复，并把第三人称动作改成游戏原生 Body、Hands、Legs 和 IK 数据链。建议先使用临时存档，实验网络功能只在好友私房测试。源码、下载、校验值、原项目链接和使用说明都放在视频简介里。

## 建议演示顺序

1. 开场先展示改版仓库、上游仓库和版本号，明确改版关系。
2. 启动游戏进入临时单人存档，再启动外置修改器并展示成功连接。
3. 按 F7 展示运行时目录，演示“角色”红色 `×` 无法选择，再拖动窗口展示响应式排版。
4. 输入一条鱼的 ID，按 F8 生成并展示拾取、背包和丢弃。
5. 输入一把枪的 ID，生成后展示拾取和射击。
6. 展示带红色 `!` 的特殊物品二次确认，但不要在正式存档生成。
7. 持枪 ADS，按 F9 后按住右键演示生物锁头、遮挡释放和换枪释放。
8. 按 F11 展示物品/生物名称、距离和遮挡变暗，再按 Insert 演示鼠标设置。
9. 如果有双客户端私有房，再展示客户端“部分保护”和一次安全物品请求；必须同时录下房主视角，不能只看客户端 HUD。
10. 最后按 F10 安全退出，并展示源码、下载位置和 MIT 许可说明。
