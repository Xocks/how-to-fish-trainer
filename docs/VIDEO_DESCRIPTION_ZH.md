## 可直接复制的视频简介

这是我基于开源项目 `fredwangwang/how-to-fish-trainer` 制作的 **Xocks 社区改版**，不是原作者发布的官方更新。原版已有生命、饱食度、空中跳、无限弹药、伤害倍率和增加金币等功能；我的改版重点新增了 **F7/F8 物品生成器**，并对生成稳定性、界面和诊断流程进行了扩展。

本次新增内容：

- F7 自动读取游戏运行时物品目录，显示物品 ID 和名称；
- F8 在人物相机前方约 2 米生成当前物品，可用于鱼、枪械和普通物品；
- 仅允许单人游戏或房主执行生成，普通联机客户端会被阻止；
- 任务和未知物品带红色 `!`，生成前需要二次确认；
- 500ms 防连点，避免短时间创建大量网络对象；
- 生成调用转到 Unity 主线程，并加入补丁恢复握手和 Mono 字符串生命周期修复；
- 物品列表会根据终端大小自动调整栏数和每页容量，缩放窗口不再残留旧画面；
- 新增脱敏诊断包和单次生成探针，方便定位闪退与兼容问题。

当前版本仍是 `v0.2.0-rc.8` 测试版，基于 Steam Build `24911270` 开发。建议使用临时存档，并优先在单人游戏或自己作为房主时测试。该工具是外部进程内存修改器，不会替换游戏安装文件，也不是安装到游戏目录中的 Mod。

## 60–90 秒口播稿

大家好，这是我在开源 How to Fish Trainer 基础上制作的 Xocks 改版。先说明一下，生命锁定、无限跳跃、无限弹药、伤害倍率和增加金币等功能来自原版；这次我主要新增的是 F7 和 F8 物品生成器。

按 F7 会从游戏运行时自动读取可生成物品，不是手工写死一个简单列表。现在目录会跟随窗口大小重新排版，大窗口一行显示四组 ID 和物品，窄窗口会自动减少栏数。输入 ID 确认后，按 F8 就会通过游戏自己的生成命令，在相机前方生成一个物品。

为了减少误操作，任务和未知物品会显示红色感叹号并要求再次确认；快速连续按 F8 也有限速。生成只允许单人游戏或房主，普通客户端会被程序直接阻止。

之前测试中遇到过物品出现后游戏闪退的问题，所以改版又加入了 Unity 主线程调度、补丁恢复握手和字符串生命周期修复。当前仍然是 RC 测试版，建议大家使用临时存档。源码、原项目链接和使用说明都放在视频简介里。

## 建议演示顺序

1. 开场先展示改版仓库、上游仓库和版本号，明确改版关系。
2. 启动游戏进入临时单人存档，再启动外置修改器并展示成功连接。
3. 按 F7 展示 85 项运行时目录，然后拖动窗口演示响应式排版。
4. 输入一条鱼的 ID，按 F8 生成并展示拾取、背包和丢弃。
5. 输入一把枪的 ID，生成后展示拾取和射击。
6. 展示带红色 `!` 的特殊物品二次确认，但不要在正式存档生成。
7. 快速按 F8 展示 500ms 限速；如果方便，再展示普通联机客户端被阻止。
8. 最后按 F10 安全退出，并展示源码、下载位置和 MIT 许可说明。
